Put official documents here as `.txt` or `.md`. Each file starts with header lines,
a blank line, then the document text:

```text
title: <document title>
issuer: ICAR
crop: <crop name, or "all">
region: <state/district>
date: DD/MM/YYYY
url: <official source URL>

<body text copied from the official document>
```

Use `ICAR` or `IMD` as the issuer when the document supports disease, irrigation,
soil, nutrient, or weather retrieval.
